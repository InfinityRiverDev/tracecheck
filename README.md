# TraceCheck

Мобильный сайт для проверки цифрового следа. Досье строится по публикациям вымышленного студента, личный отчёт — по ответу пользователя.

## Запуск

Нужны Node.js 24 и Python 3. Из каталога репозитория выполните:

```sh
node build.mjs
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Откройте [локальный сайт](http://127.0.0.1:8765/). Для статического хостинга используйте содержимое `dist/`.

Если Node.js не запускает модули прямо с SMB-пути Windows, соберите проект из локальной копии репозитория.

## Проверка

1. В ленте выберите табличку или геометку, подпись о доме и планы поездки. Откройте досье.
2. В редакторе скройте геометку и табличку. Связь с домом исчезнет, планы поездки останутся видны.
3. Перезагрузите страницу. Правки сохранятся в текущей вкладке.
4. С главной запустите самооценку. Сравните отчёты для ответов «Да, видны» и «Не уверен».
