# TraceCheck

Игра для ПК и телефона о цифровом следе. Игрок исследует специально созданные
источники одного вымышленного персонажа, проходит десять уровней, собирает
досье, получает EXP и улучшает собственные цифровые привычки.

Новая обязательная структура продукта описана в
[`docs/TRACE_CHECK_PLAN.md`](docs/TRACE_CHECK_PLAN.md), состояние миграции и
порядок интеграции — в [`docs/MIGRATION_GAP.md`](docs/MIGRATION_GAP.md).
Старый односрезовый интерфейс является переходной реализацией, а не финальной
структурой продукта.

Опубликованный сайт: https://tracecheck-team-work.intactbead1.chatgpt.site

## Запуск

Нужен Node.js 24. Из локальной копии репозитория установите обе группы зависимостей:

```sh
npm ci
npm ci --prefix client
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:3000/). Корневые `npm run build` и
`npm start` собирают React-клиент, запускают API и внутренний live-рейтинг и
отдают всё через единый Node-сервер. Порт задаётся
переменной `PORT` (по умолчанию 3000). Готовые файлы находятся в `dist/`;
их можно разместить на статическом хостинге.

Ответы и игровой прогресс сохраняются в `sessionStorage` текущей вкладки.
Интерфейс не отправляет ответы в MongoDB. «Начать заново» на главной очищает
игровую ветку и самооценку.

## Серверный API MongoDB

Для API скопируйте `.env.example` в `.env`, задайте `MONGODB_URI` и выполните
`npm run dev`. Без URI сайт работает локально, а API возвращает 503.
Проверка подключения: `GET /api/health`. Для анонимного прогресса доступны
`GET /api/sessions/:id` и `PUT /api/sessions/:id` с JSON `{ "state": { ... } }`.
Документы коллекции `sessions` имеют TTL 30 дней.

Базовая серверная авторизация новой архитектуры:

- `POST /api/auth/register` — `nickname`, `password`, `passwordConfirmation`;
- `POST /api/auth/login` — `nickname`, `password`;
- `GET /api/auth/me` — текущий безопасный профиль;
- `POST /api/auth/logout` — отзыв серверной сессии.

Пароли хешируются `scrypt`, а в `authSessions` сохраняется только SHA-256
отпечаток случайного токена. Production-cookie имеет атрибуты `__Host-`,
`Secure`, `HttpOnly`, `SameSite=Lax`; запросы изменения проверяют `Origin` и
`application/json`. На production задайте точный `PUBLIC_ORIGIN` с протоколом.
При регистрации создаётся начальный документ `progress`; также подготовлены
индексы `users`, `levels`, `progress`, `attempts`, `feedback`.

Подключение облачного сохранения к интерфейсу требует отдельного явного выбора
пользователя; автоматическая синхронизация в текущем выпуске не включена.

`MONGODB_URI` содержит секрет и никогда не должен попадать в браузер или git.
На хостинге задайте его как secret/environment variable. Команда запуска —
`npm start`, команда сборки — `npm run build`.

## Администрирование

Quiz-рейтинг хранится в коллекции `quizLeaderboardState`. Администратор входит
в игру с ником `admin`; в рейтинге ему доступны очистка очков без удаления
аккаунтов и удаление выбранного пользователя. Права проверяются сервером по
роли, а не по одному имени. Пароль и роль хранятся только в хешированном виде.

Безопасные служебные команды (нужен локальный `.env` с `MONGODB_URI`):

```sh
npm run db:audit
npm run admin:create
```

`db:audit` только читает схему, индексы и счётчики целостности, не выводя
профили или секреты. `admin:create` создаёт или перевыпускает профиль `admin`
одновременно в основной схеме и quiz-рейтинге, сохраняя остальных игроков;
сгенерированный пароль выводится один раз в терминал. Для заданного пароля
передайте его через секретную переменную `ADMIN_PASSWORD`, не через аргумент
командной строки.

Если Node.js не запускает модули прямо с SMB-пути Windows, соберите проект из локальной копии репозитория.

## Проверка

```sh
npm test
npm run build
npm run check:production
node checks/assessment.check.ts
npm run db:audit
```

Production-проверка поднимает сервер на свободном loopback-порту без MongoDB,
проверяет точный React index, JS/CSS, уведомления о шрифтах и API без конфигурации.

1. В ленте выберите табличку или геометку, подпись о доме и планы поездки. Откройте досье.
2. В редакторе скройте геометку и табличку. Связь с домом исчезнет, планы поездки останутся видны.
3. Перезагрузите страницу. Правки сохранятся в текущей вкладке.
4. С главной запустите самооценку. Сравните отчёты для ответов «Да, видны» и «Не уверен».
